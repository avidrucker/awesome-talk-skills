# Awesome Talk Skills

A small index of my public [Claude Code](https://claude.com/claude-code) skill families — each one distills a talk, book, or methodology into reusable agent skills.

## Skill repos

- **[simple-made-easy-skills](https://github.com/avidrucker/simple-made-easy-skills)** — `decomplect`: review code for *complecting* (concerns braided together that could stand apart), distilled from Rich Hickey's "Simple Made Easy."
- **[warmed-skills](https://github.com/avidrucker/warmed-skills)** — Claude Code skills distilled from Casey Muratori's talks, starting with "Where Does Bad Code Come From?" (the WARMED acronym). Talk media lives on the `talks` branch.
- **[yegor-pm-skills](https://github.com/avidrucker/yegor-pm-skills)** — eight Claude Code skills distilled from Yegor Bugayenko's XDSD methodology: practical PM rules for solo devs and AI agents.
- **[talk-distill-skills](https://github.com/avidrucker/talk-distill-skills)** — pipeline + Claude Code skill family for distilling YouTube talks into transcripts and summaries.
